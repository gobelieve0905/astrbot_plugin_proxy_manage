# 代理管理中心

为 AstrBot 提供通用的代理出口、分流规则、节点状态和连通性诊断能力。

## 0.2.3

- 支持订阅分组和自动定时刷新。
- 支持导入前预览协议、地区、命名和流量信息。
- 支持刷新失败重试、连续失败统计和错误历史。
- 支持节点单测、批量测速、延迟展示和健康标记。
- `url-test` / `fallback` 会使用已检测的节点延迟与健康状态。

## 0.2.2

- 支持解析 AnyTLS 订阅节点。
- 订阅无法识别时提示发现的协议类型。

## 0.2.1

- 支持导入和刷新多个 HTTP/HTTPS 订阅链接。
- 支持 Clash YAML 与常见代理 URI 订阅格式。
- 支持可选的 Mihomo / Clash 外部控制接口，可查看代理组并切换节点。
- 订阅地址、节点入口和外部控制密钥在页面中脱敏显示。

## 0.2.0

- Clash Verge 风格侧边栏控制台。
- 支持节点、代理组、优先级分流规则和平台绑定。
- 保留 0.1.x profiles/routes 配置并自动迁移。
- 支持配置备份与恢复上一版。

## 0.1.2

- 支持新增、删除和启停代理策略。
- 支持 Telegram、Meta、GitHub 平台模板。
- 支持精确/后缀域名匹配、规则冲突检查和保存前变更预览。
- 配置错误或保存失败时保留上一版配置。

## 0.1.1

- 页面主题跟随 AstrBot 的浅色/深色主题，也支持系统主题作为兜底。
- 代理状态、表单、诊断结果和移动端节点列表统一使用主题色变量。

## 0.1.0

- 支持直连、HTTP、SOCKS5 和 Mihomo 入口四种策略类型。
- 支持按域名预览实际命中的出口策略。
- 支持不携带业务 Token 的 HTTP/HTTPS 分阶段连通性检测。
- 支持最近代理事件和配置持久化。
- 默认只有直连策略，不会改变其他 AstrBot 请求的网络行为。
- 代理入口密钥不会通过页面状态接口返回。

插件页面位于 AstrBot 插件详情中的「页面」。配置保存为插件数据目录内的 JSON 文件。生产环境建议为 Telegram、Meta、GitHub 分别建立独立策略，并启用失败关闭，避免代理失败时自动回退直连。

本版本不实现系统级 TUN、透明代理或 DNS 接管，也不开放任意 URL 代理转发。订阅导入只解析节点元数据；Mihomo / Clash 外部控制接口默认关闭，需要用户显式配置地址和密钥。后续版本将继续完善节点测速、配置导入导出和历史版本管理。
