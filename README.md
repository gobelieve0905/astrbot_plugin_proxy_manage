# 代理管理中心

为 AstrBot 提供通用的代理出口、分流规则、节点状态和连通性诊断能力。

## 0.1.1

- 页面主题跟随 AstrBot 的浅色/深色主题，也支持系统主题作为兜底。
- 代理状态、表单、诊断结果和移动端节点列表统一使用主题色变量。

## 0.1.0

- 支持直连、HTTP、SOCKS5 和 Mihomo 入口四种策略类型。
- 支持按域名预览实际命中的出口策略。
- 支持不携带业务 Token 的 HTTP/HTTPS 分阶段连通性检测。
- 支持最近代理事件和配置持久化。
- 默认只有直连策略，不会改变其他 AstrBot 请求的网络行为。
- 代理入口密钥不会通过页面状态接口返回。

插件页面位于 AstrBot 插件详情中的「页面」。配置保存为插件数据目录内的 JSON 文件。生产环境建议为 Telegram、Meta、GitHub 分别建立独立策略，并启用失败关闭，避免代理失败时自动回退直连。

本版本不直接修改 Mihomo 配置、不读取订阅、不开放任意 URL 代理转发，也不自动切换节点。后续版本将增加可选的 provider 适配器和节点目录管理。
